Migración única: data.js → Firestore

Esta página se usa una sola vez para copiar tus productos actuales (los que tenías en js/data.js) hacia la base de datos Firestore. Después de migrar, puedes borrar esta página o dejarla (está protegida por tu inicio de sesión).

  1. Primero inicia sesión en admin.html con tu cuenta de administrador.
  2. Abre tu archivo js/data.js actual, copia el array de productos y pégalo abajo convertido a formato JSON (ver ejemplo).
  3. Revisa que cada producto tenga: nombre, descripcion, precio, categoria, imagen (URL existente de tu carpeta assets/products/), estado y destacado.
  4. Presiona "Migrar a Firestore".

Ejemplo de formato esperado:

[
  {
    "nombre": "Torta para XV años",
    "descripcion": "Torta personalizada de tres pisos.",
    "precio": 1500,
    "categoria": "Tortas",
    "imagen": "assets/products/torta-para-15-anos-4.jpg",
    "estado": "Disponible",
    "destacado": true
  }
]
O selecciona el archivo y se pega solo (evita errores al copiar).
Debes iniciar sesión como administrador en admin.html antes de migrar.
