Importar catálogo a Firestore

Esta página se usa para cargar de una vez tu catálogo completo (nombre, descripción, precio, categoría y foto de cada producto) hacia la base de datos. Puedes usarla las veces que necesites para agregar lotes nuevos de productos.

  1. Primero inicia sesión en admin.html con tu cuenta de administradora.
  2. Regresa a esta página.
  3. Toca "Elegir archivo" y selecciona el archivo productos_import.json que te compartí.
  4. Presiona "Importar a Firestore". Verás el progreso producto por producto.
Debes iniciar sesión como administradora en admin.html antes de importar.
